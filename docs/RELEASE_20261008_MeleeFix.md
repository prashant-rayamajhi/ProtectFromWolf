# ProtectFromWolf — 近接攻撃修正版

## 起動方法

Releaseの **ProtectFromWolf.zip** をすべて展開し、**Windows/ProtectFromWolf.exe** を起動してください。付属のデータやライブラリも必要です。ZIPに編集用ソースコードや元アセットは含めていません。

## 更新内容

- 雑魚・中間ボス・ラストボスの近接攻撃中に距離を確認し、相手が射程外へ逃げたらモーションと命中判定を停止。
- 近接攻撃の自動連続再生を解除し、次の攻撃は状況を再判断してから開始。
- 接近中の停止判定を毎フレーム行い、剣の射程の約9割で止まるよう調整。相手のカプセル半径の二重加算も補正。
- ボスの一振り約1.12秒に対して終了ブレンドが1秒あったため、実行時の専用モーションでは0.15秒に短縮。元アセットは維持。
- 古い終了タイマーによる次の攻撃への干渉を避け、近接攻撃の終了をモーションの終了と同期。
- 敵の構え上げを高速化し、構えが終わる前には発射しない条件を維持。
- 味方から戦闘情報を受け取った際の巡回中断と、味方の移動先を考慮した射撃位置の選択を改善。
- ボスの移動速度・視野・発見確認の頻度を調整。レーザー前には装備中の武器を収納。

## 確認したこと

UE 5.7.4でビルドし、敵AIの自動テスト25件で失敗0件を確認しました。うち2件は、テスト用のメッシュなしキャラクターに関する警告付きです。

エディター上で雑魚・中間ボス・ラストボスの停止、近接攻撃、相手の逃走後の追跡を記録し、画面と照合しました。中間ボスの約0.2秒で攻撃が切れる現象を再現して終了ブレンドを修正し、修正後は同条件で約0.88秒まで継続することを確認しています。

試験には無敵設定、開始位置の変更、外部視点、確認用の描画設定を使用しています。通常プレイで最初から最後まで検証した結果ではなく、全条件で不具合がないと保証するものでもありません。これらの試験設定は配布用マップに保存していません。
