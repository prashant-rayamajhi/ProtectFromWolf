# ProtectFromWolf

## Windows版

**ProtectFromWolf.zip** 全体を展開し、**Windows/ProtectFromWolf.exe** を起動してください。EXEだけを移動すると起動できません。実行に必要なデータ・ライブラリを含み、編集用ソースや元アセットは含みません。

## 2026年10月8日の更新

- 人狼の移動速度を直前版から約30.4%増加。人型の速度は維持。
- パンチにも命中時の短いヒットストップを追加。最後のキックは長めの停止とカメラシェイク。
- 命中位置に小型のエフェクトを追加。同じ攻撃で重複生成しないよう制御。
- キックの吹き飛ばしを水平60%、上方向65%に抑制。ボスほど飛びにくい設定は維持。
- タイトル・戦闘・クリア・ゲームオーバーのBGMを入れ直し、曲ごとの再生音量を調整。

## 確認範囲

人狼の前後左右移動をエディターで測定し、最高速度1,822.5cm/秒とAnimation Blueprintへ渡る速度が一致することを確認しました。Blend Spaceには速度に合わせて再生速度を補正する設定があります。今回、この歩行設定自体は変更していません。

足元が画面から切れる場面があったため、すべての足滑りや見た目の違和感が解消したという報告ではありません。戦闘全体の通しプレイ、音量の聴感評価も未完了です。検証では描画負荷を下げています。

命中時のヒットストップ・重複ダメージ防止・敵の種類別ノックバックは自動テストで確認しました。4画面のBGM再生状態も確認しています。これらは実戦の手応えを保証する試験ではありません。

## 掲載コード

既存の担当コード46ファイルを現行プロジェクトと照合し、差分がないことを確認しました。今回の変更を含む共有コードを、新たに個人の成果として掲載していません。UI・Animationフォルダも掲載対象外のままです。
