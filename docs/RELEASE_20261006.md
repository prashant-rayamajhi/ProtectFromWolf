# 2026年10月6日 更新記録

- ジャスト回避の操作案内を画面下寄りの小型・半透明カードへ変更しました。

## 確認範囲

UE 5.7.4のEditorビルドと入力切り替えの自動テストが成功しました。ゲームパッドボタン、キーボード、スティックのしきい値、マウスクリック、入力を消費しないことを確認しています。

このテストは入力イベントによる検査です。実物のコントローラー、全解像度の描画、最新パッケージの全編プレイは未検証です。敵の密集と足滑りには未解決の条件があります。

## 配布物

Windows版ZIPは実行に必要なファイルのみです。ソース・編集用アセットは含みません。ZIP全体を展開して `Windows/ProtectFromWolf.exe` を実行してください。

ゲーム内素材の権利は各権利者に帰属します。配布ZIPは素材の抽出・再利用を許諾するものではありません。
