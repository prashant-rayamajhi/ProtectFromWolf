# ProtectFromWolf — 射撃雑魚の構え速度調整版

Releaseの **ProtectFromWolf.zip** をすべて展開し、**Windows/ProtectFromWolf.exe** を起動してください。付属データも必要です。編集用ソースコードはこのZIPに含まれません。

## 更新内容

- 射撃雑魚が銃を構え、照準を合わせる動作を従来の1.35倍から1.62倍へ変更しました（現在比20％増）。
- 照準完了通知と発射可能区間の判定を維持し、アニメーションの進行に合わせて発射を開始します。
- 発射開始後のアニメーションは通常速度へ戻します。連射速度、ボス、近接武器の構え速度は変更していません。
