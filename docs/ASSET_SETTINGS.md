# 敵武器のBP設定移行（2026年11月2日）

## 今回の更新範囲

`AEnemyGun`、`AEnemyBullet`のヘッダーと実装を、開発プロジェクトの現在の内容に合わせました。これら2クラスから、ゲームアセットの固定パスによる読み込みを除いています。

この更新は全クラスの移行完了を意味しません。弾道表示の共通クラス、敵本体、変身、BGM、画面演出などには引き続き移行対象があります。開発プロジェクトのC++関連151ファイルを検索し、今回の修正後も実行時コード20ファイルに固定参照などの候補を検出しています。テスト用参照は別集計です。

## BPで指定する内容

| BP | 設定 | 用途 |
| --- | --- | --- |
| BP_EnemyGun / BP_BossGun | Meshコンポーネント | 銃のメッシュとマテリアル |
| 同上 | m_bulletClass | 発射する弾BP |
| 同上 | m_enemyMuzzlePulseNiagara | 銃口のNiagaraエフェクト |
| 同上 | m_muzzleScale / m_muzzleLife | 銃口エフェクトの大きさと表示時間 |
| 同上 | m_muzzleSound / m_minionPulseSound | 通常・雑魚敵用の銃声 |
| BP_EnemyBullet | m_impactSound（Effects / Audio） | 着弾音。未設定なら音を再生しない |

開発プロジェクトでは、弾BPの着弾音に従来使用していた`SFX_BeamImpact`を設定しました。銃BPとボス銃BPの弾クラス・銃声・発射エフェクトは従来の設定を保持しています。

ゲーム開始時に銃の射撃間隔や銃声を固定値で上書きせず、BPの設定を維持します。タイマーが動かなくなる不正な値のみ補正します。

旧Niagaraの弾道・着弾素材は実際の敵弾表示に使用されていなかったため、自動読み込みを削除しました。既存BPの互換性のため旧コンポーネントとプロパティ自体は残しています。現在の弾道・着弾表示は`UCombatTracer`が担当し、この共通クラスの固定参照の移行は未完了です。

## 検証範囲

- UE 5.7.4のEditorターゲットをビルド。
- 開発プロジェクトで回帰テスト44件を実行。成功37件、警告付き成功7件、失敗0件。
- BPの着弾音が開始時に上書きされないことと、未設定時に固定音へ置き換わらないことを追加テスト。
- 敵銃・ボス銃の既存アセット参照と、弾BPの保存内容を確認。

その後、同日のShipping版を再ビルドし、起動とタイトルからゲーム画面への遷移を確認して[配布EXE](https://github.com/prashant-rayamajhi/ProtectFromWolf/releases/tag/v2026.11.02-bp-weapons)も更新しました。全3戦闘空間の通しプレイ確認は行っていません。

## コード紹介用リポジトリについて

BP、メッシュ、音声、Niagaraなどのアセットはこのリポジトリに含めていません。コードのみを取得してもゲームは起動できません。ゲームへ取り込む際は、対応するBPの設定も必要です。
