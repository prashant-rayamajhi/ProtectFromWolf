# ProtectFromWolf — ボスの射撃・レーザー速度調整版

**ProtectFromWolf.zip** をすべて展開し、**Windows/ProtectFromWolf.exe** を起動してください。付属データも必要です。配布ZIPには編集用ソースコードを含めていません。

## 更新内容

- 中間ボス・ラストボスの銃の構えを1.35倍から1.62倍へ変更しました（現在比20％増）。
- ボスの射撃中のアニメーションを1.2倍速とし、発射間隔・バースト間隔も1.2で割って短縮しました。
- レーザーの溜め・照射アニメーションを1.2倍速にし、発射開始・終了とエフェクト終了の時刻を合わせました。
- ジャスト回避の合図を、高速化後のレーザー発射時刻に合わせています。
- 雑魚の速度は直前の配布版から変更していません。
