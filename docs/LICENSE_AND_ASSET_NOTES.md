# 素材・コード・ライセンス確認

## 公開範囲

- コード紹介用リポジトリ: Public
- ゲームプロジェクト全体: 非公開
- Contentフォルダ: 全て除外
- チームメンバー作成コード: 除外
- 作成者を確認できないコード: 除外
- ライセンスファイル: 追加しない
- 完成したWindowsゲーム: ソースとは別にGitHub Releasesで配布

## 理由

Contentには1,028件の`.uasset`と18件の`.umap`を含み、画像、音声、3Dモデル、Animation、Blueprint等の作成者と再配布条件をファイル単位で確認できません。Unreal Engine Marketplace、Fab、外部配布サイト、チームメンバー制作物が混在している可能性があります。

旧履歴はプロジェクトの一括コミットが中心で、ファイル単位の著作者を履歴だけでは証明できません。そのため、担当申告とファイルの責務が一致する主要コードだけを選定し、その他のコードは掲載対象から除外しました。

本リポジトリには明示的なオープンソースライセンスを付与していません。コードは採用選考での閲覧と実装説明を目的として公開しており、第三者による再利用、改変、再配布を許諾するものではありません。

## ソースリポジトリへ含めないもの

1. Unreal Engineアセットを含むContentフォルダ
2. Blueprint、マップ、画像、音楽、効果音、3Dモデル、Animation
3. チームメンバーが作成したコード
4. 作成者や再配布条件を確認できないファイル
5. ビルド済みゲーム、キャッシュ、一時ファイル（ゲーム本体のみReleasesで別配布）

## Windowsゲームの配布

2026年9月26日版を所有者の公開指示に基づいてReleasesへ掲載しています。編集可能な元アセットやプロジェクト全体を公開するものではありません。各素材の権利は各権利者に帰属し、ゲームに含まれる素材を抽出して再利用する許諾は含みません。素材ごとの配布条件については所有者による管理・確認が必要です。
