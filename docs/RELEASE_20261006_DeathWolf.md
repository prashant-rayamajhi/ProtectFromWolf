# ProtectFromWolf

## Windows版

Assetsの **ProtectFromWolf.zip** をダウンロードし、ZIP全体を展開して **Windows/ProtectFromWolf.exe** を起動してください。
実行に必要なデータとライブラリを含みます。編集用のC++ソース、プロジェクト、元アセットは同梱していません。
GitHubの「Source code (zip / tar.gz)」は自動生成されるコード紹介用のアーカイブで、ゲーム本体ではありません。

## 今回の変更

- 死亡モンタージュの終端で立ち姿へ戻らず、ゲームオーバーへの遷移まで倒れた姿勢を保持。
- 人狼の攻撃倍率を従来設定から20%増加。
- 人狼の移動速度を従来から15%増加。
- 変身の持続時間を従来から30%延長。現行設定では10秒から13秒。

## 確認範囲

UE 5.7.4のエディターで、自動入力・ダメージ付与を併用して、人型と人狼の死亡後の画面遷移、変身解除後の移動速度・高さの復元を確認しました。
足滑りの見た目、攻撃力の実戦比較、ゲーム全体の通しプレイは未完了です。死亡演出のカメラ構図にも改善の余地があります。
GPUクラッシュ後の確認は描画負荷を下げた設定で行っており、通常設定での問題解消を保証するものではありません。
